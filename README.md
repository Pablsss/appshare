# AppShare
Browse small apps by category, try interactive demos, and share or remix a project with creator attribution. Profiles and submissions stay in this browser.
    
Run `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist` and open http://localhost:4173. With Node 22 or later, run `node --test checks.mjs` to check the catalog and submission links.
